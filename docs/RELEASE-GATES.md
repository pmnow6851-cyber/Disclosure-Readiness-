# Release and commercial-readiness gates

The owner must explicitly approve each release stage. Draft branches and proposals do not authorise publishing.

1. **Content integrity** — label source, date, provenance, verification status, and uncertainty; no invented evidence.
2. **Privacy by design** — UK GDPR lawful basis, retention, access, export/deletion and privacy notice reviewed before user submissions.
3. **Security** — private data store, verified auth, least privilege, no client secrets, abuse controls, incident channel and tested data deletion.
4. **Accessibility** — phone-friendly responsive UI, keyboard access, focus indicators, readable contrast and WCAG testing.
5. **Commercial** — approved disclosures, refund/support terms, verified owner-controlled payout route and explicit £0 additional-spend decision.
6. **Android / stores** — signed Android build, real-device tests, store policy, account deletion where applicable and Data safety forms.
7. **Governance** — owner review, reversible changes, audit evidence and recovery plan.
8. **Go-live** — explicit written owner approval before hosting, domain, payment or store activation.

No gate should be marked PASS without direct verification.
