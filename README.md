# DISCLOSURE — Readiness Hub

**Status: foundation proposal / not released — PUBLIC REPOSITORY HOLD**

DISCLOSURE is a proposed educational web hub and cross-platform app for assessing claims, checking source provenance and communicating uncertainty. It is **not** a verified evidence repository, news authority, live disclosure service or operational commercial product.

## Public visibility warning
This repository and its draft pull-request branches are currently **public**. Treat every commit, issue, pull request, attachment, workflow log and discussion as publicly observable. Do not put testimonies, allegations about identifiable people, case material, personal information, medical/location records, private URLs, internal research, unpublished IP, customer records, credentials or payout information here. Do not invite confidential user submissions.

The intended development environment is private, but **its visibility has not been changed**. Making a repository private later does not retract earlier copies or public forks. If sensitive data has ever been committed, assess exposure and rotate affected credentials; editing or deleting one file is insufficient.

## Proposed public-safe scope
- Static, informational landing-page draft in `site/`, **not hosted or released**.
- Source-literacy guidance distinguishing documented facts, allegations, hypotheses, opinions and unknowns.
- An explicit disclaimer that claims and generated imagery are not authenticated evidence.
- A future, separately reviewed private intake system only after legal, safeguarding, retention and access controls are approved.
- A future Android app and monetisation only after testing and explicit owner approval.

## Current limitations
The `main` branch contains only the initial README. The rest of this foundation is **proposed in draft PR #1**, not approved for merging. The GitHub Actions draft guard is a limited static check, **not** a security audit, secret-clean certificate or release authorisation. A `CODEOWNERS` file alone does not enforce owner-approved merges; branch settings and protection must be checked separately.

No verified deployed website, private database, user accounts, payment checkout, production backend, signed Android build or store listing is provided by this proposal.

See [project status](docs/STATUS.md), [connections register](docs/CONNECTIONS.md), [release gates](docs/RELEASE-GATES.md) and [security policy](SECURITY.md).

Open `site/index.html` locally to inspect a static placeholder. It collects no information and contains no upload, sign-in, analytics or payment integration.
