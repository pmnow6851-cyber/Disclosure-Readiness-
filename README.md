# DISCLOSURE — Readiness Hub

**Status: foundation proposal / not released**

DISCLOSURE is a proposed cross-platform educational web hub and app for helping people assess claims, organise source references and understand uncertainty. It is **not** a verified evidence repository, news authority, live submission service or operational commercial product.

## Scope
- Public educational landing page (draft only in `site/`).
- Clear distinction between documented information, allegations, hypotheses and unknowns.
- Future private evidence workflow only after authentication, privacy, safeguarding and lawful storage arrangements have been tested.
- Future Android / cross-platform app and monetisation only after separate owner-approved review.

## Current state
The repository is **public**. Do not upload testimonies, personal information, evidence files, contacts, account identifiers, secret keys or internal research. No actual submission form, user accounts, payments or production backend have been connected.

See [project status](docs/STATUS.md), [connections register](docs/CONNECTIONS.md), [release gates](docs/RELEASE-GATES.md) and [security policy](SECURITY.md).

## Local public-site preview
Open `site/index.html` in a browser. This is a static, informational placeholder; it does not collect information, transact or publish itself.

## Operating boundaries
- £0 additional spend and no billing activation.
- Owner retains full control of accounts, IP, source, releases and payments.
- No repo duplication or coupling to RANDA.MKCOOL.
- GitHub proposals are review-only; no unattended deployments, merges or publication.
- Do not present generated graphics, speculative claims or fictional demonstrations as verified evidence.
