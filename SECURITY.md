# Security and responsible disclosure

This is a public repository. **Never post actual disclosures, evidence, personal data, secrets, location records, recovery codes, passwords, tokens or confidential communications in GitHub issues, commits or pull requests.**

Security reports containing non-public details must not be posted publicly. A private security reporting channel has **not yet been verified or enabled**. The owner must configure and verify an appropriate private channel before any user-submitted evidence or sensitive report is accepted.

Until then, this repository accepts only generic, non-sensitive technical feedback. No production evidence upload, payment, sign-in or third-party integration is approved.

No change may activate collection, tracking, analytics, uploads, payment, email, external APIs or deployment without explicit owner approval and a privacy/security review.
